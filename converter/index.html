Phun config converter

Convert old Lua-table configuration files to JSON before the Build 42 migration. Everything runs locally in this page; no files are uploaded.

Convert files

Choose one or more old .txt or .lua files. The original files are never changed.

Convert pasted text

Paste a complete file beginning with return { ... }.

This converter accepts data tables only. It intentionally rejects executable Lua such as functions, calls, assignments, and expressions.
