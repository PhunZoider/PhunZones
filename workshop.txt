description=[list]

description=[*]Block Bandits (requires Bandits 2)
description=[*]Prevent safehouse creation
description=[*]Restrict picking up or placing objects
description=[*]Restrict dismantling and crafting

description=[*]Prevent fire spread
description=[*]Block player entry to specific zones

description=[/list]

description=[list]
description=[*]No external dependencies (PhunLib no longer required)
description=[*]Build 42+ focused (B41 support retired)
description=[*]Major performance improvements
description=[*]Completely redesigned zone editor UI
description=[*]True inheritance system — define base zones (Easy / Medium / Hard, etc.) and let other zones inherit their settings. Change it once, update everywhere.
description=[/list]

description=[h2]B42.20.4: Migrating customisations[/h2]
description=
description=Build 42.20.4 removed the functions used to read and write configuration files. Any existing PhunZones.txt customisations you have will need to be re-created or converted to JSON.
description=
description=[b]Single-player[/b]
description=1. Find your customisations at %UserProfile%/zomboid/Lua/PhunZones.txt.
description=2. Open the [url=https://phunzoider.github.io/PhunZones/converter/]Phun configuration converter[/url].
description=3. Select or drag PhunZones.txt into the converter and download the resulting PhunZones.json file.
description=4. Place PhunZones.json in the same %UserProfile%/zomboid/Lua folder.
description=
description=[b]Multiplayer[/b]
description=Find your customisations at <game dir>Lua/PhunZones.txt. Note that Clients do not have the server's configuration file so they do not need to do anything. Convert it with the same tool and place PhunZones.json beside the old file.
description=
description=The converter runs locally in your browser; configuration files are not uploaded.
description=
description=If a v1 customisation is migrated by the mod, its JSON backup is written to <game dir>/lua/PhunZones_Old.json.
description=[hr]
